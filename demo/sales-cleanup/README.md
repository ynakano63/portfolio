# デモ：売上明細CSVの整形と月別集計

月ごとに書式がばらばらな売上明細CSVをまとめて読み込み、表記をそろえ、月別・カテゴリ別に集計する Python スクリプトのデモです。

> **このデモについて**
> 公開用に新しく制作したもので、実務で作成したコードではありません。
> データはすべて乱数で生成した架空のもので、実在の企業・取引・金額とは関係ありません。

## 構成

```
sales-cleanup/
├── clean_sales.py          整形・集計スクリプト（本体）
├── make_sample_data.py     架空データの生成スクリプト
├── input/                  処理前のCSV（3か月分）
│   ├── sales_2026-07.csv   UTF-8
│   ├── sales_2026-08.csv   Shift_JIS（Excelで保存した想定）
│   └── sales_2026-09.csv   UTF-8・列名が他の月と異なる
└── output/                 処理後のファイル
    ├── cleaned_sales.csv     整形済みの明細
    ├── needs_review.csv      人の確認が必要な行と、その理由
    ├── monthly_summary.csv   月別・カテゴリ別の集計
    └── report.txt            処理件数のレポート
```

## 実行方法

Python 3.9 以降が必要です。標準ライブラリだけで動くため、追加のインストールは不要です。

```bash
cd demo/sales-cleanup
python clean_sales.py
```

`output/` フォルダに4つのファイルが書き出され、画面にレポートが表示されます。
入力・出力フォルダを変える場合は次のように指定します。

```bash
python clean_sales.py --input 入力フォルダ --output 出力フォルダ
```

架空データを作り直す場合（シード固定のため、毎回同じ内容になります）：

```bash
python make_sample_data.py
```

## 入力データ

3か月分・合計135行の売上明細です。次のような「現場でよくある不ぞろい」を意図的に混ぜています。

| 不ぞろいの種類 | 例 |
|---|---|
| 日付の書式 | `2026/7/20`、`2026-07-10`、`2026年9月11日`、`２０２６／７／１５` |
| 数値の書式 | `10,500`、`￥300`、`9600円`、`４８００` |
| 取引先名の表記 | `㈱あおば商事`、`（株）あおば商事`、`ﾐﾅﾄ工房`、前後の空白 |
| ファイルごとの違い | 文字コード（UTF-8 / Shift_JIS）、列名（`日付` / `売上日` など） |
| 入力ミス | 同じ伝票の二重入力、空行、金額の空欄、検算が合わない行 |

## 処理内容

1. フォルダ内のCSVをすべて読み込む（文字コードは自動判定）
2. 月によって違う列名を共通の列名に読み替える
3. 全角英数字・半角カナ・`㈱` などを統一し、余分な空白を取り除く
4. 日付を `YYYY-MM-DD` に、数量・単価・金額を整数にそろえる
5. 空行と、内容が完全に同じ重複行を取り除く
6. 日付が読めない行、金額が空欄の行、`数量 × 単価` と金額が合わない行は、**削除や推測での補完をせず** `needs_review.csv` に理由を付けて分離する
7. 整形済みの明細を、月別・商品カテゴリ別に集計する
8. 読み込んだ行数と、各出力の行数の合計が一致するかを検算する

同梱の入力データを処理した結果です。

  重複を除外   : 9行

出力CSVは、Excelでそのまま開けるように BOM 付き UTF-8 で保存しています。

## このデモの範囲

- 取引先名の統一は、全角・半角と `㈱`・`（株）`・`㈲`・`（有）` の違いに対応しています。「あおば商事」と「アオバ商事」のような読みの違いは、対応表を別途用意する必要があります。
- 重複の判定は「整形後の内容が完全に同じ行」のみです。
- 実際の業務では、データの形式や判断ルールをヒアリングしたうえで処理を設計します。
